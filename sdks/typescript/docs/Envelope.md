# Envelope

Envelope type used for the mailing. none means the mailpiece mails itself: postcard, brochure or flat only.

## Enum

* `Standard` (value: `'standard'`)

* `None` (value: `'none'`)

* `Flat` (value: `'flat'`)

* `DoubleWindow` (value: `'double_window'`)
